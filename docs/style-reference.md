# Style reference - Flame of Recca: The Game (pilot lines, approved in-game 2026-10-15)

## Voices
| Character | Voice |
|---|---|
| Recca Hanabishi | hot-headed, loud, slangy ("Outta my way!", "gonna"), calls Yanagi "Princess", calls Domon "Domon" or insults him ("French Moai") |
| Yanagi Sakoshita | gentle, polite, soft |
| Domon Ishijima | rough tough guy, boastful ("The great Domon!"), calls Recca "Hanabishi"; 固羅 (コラ) -> "Hey!" / "Oi!" |
| Fuko Kirisawa | tomboy, teasing, energetic |
| Tokiya Mikagami | cold, curt, formal; calls Yanagi "Yanagi" |
| Kaoru Koganei | cheerful kid; "Big Bro Recca" |
| Kurei | cold, regal, contemptuous |
| Koku (old man) | goofy old man, archaic ("Now hold it right there!", "ye", "methinks" sparingly); loves English buzzwords (ワンダホー -> "Wonderful-o!", ビューティフル -> "Beautiful!") |
| Kagero | calm, motherly, polite; as Kage Hoshi more formal |
| Kashamaru | archaic samurai ("...de gozaru" -> stiff old-fashioned English: "I daresay", "this one") |
| Koran Mori | megalomaniac, sneering |
| Mokuren | manic, cackling ("Hyahahaha!") |
| Kadotsu | broken, primitive speech ("You. Who? Hokage...?") |

Corrected example: the member-list placeholder `σ１２３４５６７８９０１` prints the names WITH a trailing comma
("Domon, Fuko, Mikagami,"), so the English after it must read on naturally from a comma (", any of them...",
", that's Σ of you!"). Never put "and" or a verb right after it.

Unofficial fan translation of the Japanese Game Boy Advance game "Recca no Honoo - The Game"
(Konami, 2001). This archive contains only a patch; no ROM data. Do not ask for, and do not share,
pre-patched ROMs.

How to patch
  Apply {patch} to the base ROM with any BPS patcher (Flips, beat, or RomPatcher.js online).
  The patched ROM is larger than the original (new text and font data are appended); that is expected.
  The game uses SRAM saves, which are unaffected. Start the game from a cold boot (no savestates made
  with the Japanese version).

What is translated
  - Full story mode script (all characters' stories, training chapter, Kurei's story, endings)
  - All menus, help bars, save panel, option dialogs, sound test names, database profiles
  - Graphics text: opening text crawl, staff roll, "THE END" card, database name list and buttons,
    the "Continue" button, chapter title cards, episode-clear "Continue" / "Quit" buttons; name plates respelled to the official English romanisation
    (Kurei, Fuko, Koku, Kukai, Kagero, Saicho).
  - English uses a variable-width font built into the patch.
  - Names follow the official English (Viz) "Flame of Recca" spellings, given name first, no honorifics.

Known issues
  - The title logo keeps its Japanese kanji (it is the series logo and already carries the English
    title "Flame of Recca").
  - Staff names in the credits are romanised from kanji; some readings may differ from the
    staff members' own spellings.
  - The save-panel label for super special moves reads "Super Specials" (6-character slot).
  - Link-cable (two GBA) screens were not tested on hardware.

Tested in MesenCE 2.2.1 (GBA, with BIOS).
